# clashboxresources

mihomo 配置覆写脚本仓库，当前主要包含 `mihomoScript.js`（适配 Bettbox / clashbox）。

原始脚本修改自 [AIsouler/MyClash](https://github.com/AIsouler/MyClash)，本仓库版本在此基础上做了修复与增强：GitHub 分流域名补全、规则集路径修正、节点处理健壮性提升、节点选择模式扩展。

---

## 一、脚本能做什么

`mihomoScript.js` 会读取你的机场订阅配置，重新生成一份完整 mihomo 配置：

- **节点清洗**：剔除官网/流量/到期等垃圾信息节点，处理重名、零宽字符、缺失名称等异常项
- **自动分组**：按地区生成「香港 / 日本 / 美国 / 新加坡 / 台湾」等策略组，并可生成自动选择子组
- **分流规则**：为 YouTube、Google、AI、GitHub、Telegram、Netflix、Spotify 等生成独立策略组与规则
- **节点选择模式**：支持「延迟优先」与「延迟 + 测速加权评分」两种自动选点模式
- **广告拦截**：基于规则集 REJECT 广告域名
- **国内直连**：私有网络、国内域名与常见国内服务自动直连，避免无谓走代理

## 二、部署方式

本脚本为 **mihomo 覆写脚本**，请在支持「覆写脚本 / 全局扩展脚本」的客户端中使用（如 Bettbox、clashbox 等 mihomo 系客户端）。

推荐步骤：

1. 打开客户端的订阅 / 配置管理页
2. 找到「覆写脚本」或「全局扩展脚本」入口，新建脚本
3. 将本仓库 `mihomoScript.js` 的完整内容粘贴进去并保存
4. 让目标订阅引用该脚本，或启用为全局脚本
5. 重新拉取一次订阅，使覆写生效

> 若客户端同时提供「Merge 覆写」与「脚本覆写」，建议二者只用其一，避免重复覆写、规则顺序冲突。

## 三、常用开关说明

所有开关集中在脚本顶部 `ruleOptionsEnable` 区域，`true` 为启用、`false` 为禁用。

### 1. 基础策略组

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| `手动选择` | `true` | 生成手动选择策略组 |
| `自动选择` | `true` | 生成自动选择策略组 |
| `负载均衡` | `true` | 生成负载均衡策略组 |

### 2. 分流策略组

包括 `FCM`、`YouTube`、`Google`、`AI`、`GitHub`、`Microsoft`、`Apple`、`Telegram`、`Steam`、`TikTok`、`Twitter`、`Meta`、`Line`、`Netflix`、`Emby`、`PikPak`、`Spotify`、`Crypto`、`PayPal`、`Patreon`、`EHentai`、`AdBlock` 等。

关闭某个开关后，对应策略组、规则与规则集都不会出现在最终配置中。

### 3. 节点选择模式（重要）

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| `延迟选择节点` | `true` | 仅按延迟排序，适合大多数场景 |
| `延迟测速加权评分` | `false` | 同时参考延迟与带宽，适合需要大流量的场景 |

二者建议只开启一个。**同时开启时以「延迟测速加权评分」优先**。

切换后，全局「自动选择」组、极简模式自动组、各地区「…自动选择」组会统一生效。

想调整加权模式的倾向，可修改脚本中的 `speedTestBytes`：

- 调大（如 `307200`，即 300KB）：更侧重带宽，但每次测速流量同步增加
- 调小：更接近纯延迟排序

> 说明：mihomo 的 `url-test` 只会按一个总耗时排序，不支持自定义评分公式。这里的“加权”是通过下载固定大小文件实现的，即让「传输耗时」参与总耗时评估。

### 4. 其他常用开关

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| `极简模式` | `false` | 只保留默认代理/自动选择/直连等少量分组 |
| `生成地区自动选择组` | `true` | 为每个地区组额外生成「…-自动选择」子组 |
| `隐藏地区手动选择组` | `false` | 在界面隐藏地区手动组 |
| `单地区归属` | `true` | 名称命中多个地区时，只归入首个地区组 |
| `过滤非地区节点` | `true` | 过滤含官网/流量/到期等字样的节点 |
| `屏蔽国外QUIC` | `true` | 屏蔽国外 UDP/443，规避部分节点 UDP 质量问题 |
| `代理IPV4优先` / `代理IPV6优先` | `false` | 两者同时开启时不生效 |

## 四、自定义节点

如需手动添加自己的节点，可编辑脚本中的 `customizeProxies`：

```js
const customizeProxies = [
  {
    name: '自建-日本-01',
    type: 'vmess',
    server: 'example.com',
    port: 443,
    uuid: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx',
    alterId: 0,
    cipher: 'auto',
    tls: true,
    servername: 'example.com',
    network: 'ws',
    'ws-opts': { path: '/path', headers: { Host: 'example.com' } },
  },
];
```

自定义节点不参与订阅节点的过滤逻辑；与订阅节点重名时会自动添加 `自建-` 前缀。

## 五、地区识别规则

脚本通过正则识别节点地区，支持以下写法：

- 旗帜与中文：`🇭🇰`、`香港`、`日本`、`新加坡`、`台湾`
- 英文与缩写：`HK`、`HongKong`、`JP`、`Japan`、`US`、`America`、`SG`、`Singapore`、`TW`、`Taiwan`
- 常见城市：`东京`、`大阪`、`洛杉矶`、`西雅图` 等

当节点名同时命中多个地区（如「台湾家宽 日本中转」）：

- `单地区归属: true`：按名称中最先出现的地区归入单一分组，且国旗与分组保持一致
- `单地区归属: false`：归入全部命中的地区组（旧行为）

## 七、注意事项

- 脚本会对订阅做全量覆写，最终的 mixed-port、DNS、TUN 等字段以脚本输出为准
- 修改开关后需要重新拉取订阅才能生效
- 若某个分流服务访问异常，先检查对应开关是否开启，再检查其规则集能否正常下载
